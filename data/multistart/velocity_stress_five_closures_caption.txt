Full-channel velocity (top) and Reynolds shear stress (bottom) at Re_tau=1000, one frozen checkpoint per closure, 10,000 shared initial conditions each. One curve per distinct verified root. Stress is reconstructed using the same convention and cell-gradient stencil as the paper: tau/u_tau^2 = (1-y/h) - nu*dU/dy; DNS stress is reconstructed from the DNS velocity by the identical procedure. Dashed black: DNS; brown: non-physical solution; blue: physical solution. Colour convention: relative weighted velocity error below 5% is blue except for C0, where the user requests the secondary near-DNS root (root0, 3.9033% error) be brown; only the closest C0 root (root2, 0.4757% error) is blue. This explicit display classification is not an independent test of physical admissibility and does not change the recorded errors or root counts. Independent linear velocity ranges show the minimum and maximum of all roots and DNS, with 4% padding. Root counts: A0 7, A1 1, B0 93, B1 1, C0 4.
